What is go-nokogiri?

go-nokogiri is a pure-Go (CGO_ENABLED=0) XML/HTML parser with XPath and CSS queries and libxml2-faithful serialization — the parsing and DOM core in the Nokogiri tradition, with no libxml2 and no cgo.
